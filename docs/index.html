What it does

One small bridge between two coding agents.

Connect runs as a local MCP server. Claude can ask Codex to inspect the working tree, keep a conversation across sessions, and choose a safe amount of reasoning for each request. Reviews are read-only. Only an explicit implementation request can write inside the workspace.

Commands and technical details +

/connect:ask <question> — ask Codex

/connect:threads — list recent threads

/connect:resume <threadId> <question> — continue a thread

/connect:config — choose model and reasoning effort

/connect:doctor — check the integration

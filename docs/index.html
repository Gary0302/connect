Free, open-source Claude Code plugin

Let Claude Code get a second opinion from Codex.

Connect plugs OpenAI Codex into Claude Code. When a change is risky, Claude sends it to Codex for review, checks what Codex found against your code, and fixes what holds up — all in the same session.

How it works

Two models, one terminal.

  1. You work in Claude Code as usual.Nothing changes about how you use it.
  2. Claude calls Codex when it helps.Subtle bugs, risky diffs, disputed design calls — or whenever you say “ask GPT”. You can also run /connect:ask yourself.
  3. Codex reads your code, read-only.It looks at the real files, so nothing needs to be pasted, and it can't change your tree.
  4. Claude checks the answer before acting.Codex's reply is treated as a second opinion, not as fact. The thread is saved, so you can continue it later.

Install

Two commands.

You need Claude Code, Node.js 18+, and the standalone Codex install signed in to your ChatGPT account. macOS or Linux.

terminal
claude plugin marketplace add Gary0302/connect
claude plugin install connect@connect-local

Restart Claude Code, then run /connect:doctor to check that everything is connected.

/connect:ask <question>send a question to Codex yourself
/connect:threadslist earlier Codex conversations
/connect:resume <id> <question>continue one of them
/connect:configpick the Codex model and reasoning effort
/connect:doctorcheck the setup

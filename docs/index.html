Install

Three commands.
No npm install.

Terminal
# Install the standalone Codex app
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# Add and install Connect
claude plugin marketplace add Gary0302/connect
claude plugin install connect@connect-local

Restart Claude Code, then run /connect:doctor. That’s it.

Requires macOS or Linux, Node.js 18+, Claude Code, and a signed-in standalone Codex app.

Why it exists

A second model catches different mistakes.

Claude stays in charge of your session. When another perspective would help, it asks Codex against the real working tree and brings the answer back.

Each request gets an explicit reasoning level, token ceiling, and sandbox. Reviews stay read-only. Only an implement request can write inside the workspace.

Codex threads persist across Claude Code restarts, daemon restarts, and reboots, so an earlier discussion can continue without starting over.

A real session

This README was reviewed through Connect.

Claude read the repository, rewrote its README, then asked Codex to check the documentation against the code.

The first review reached the 200k-token ceiling before returning an answer. Claude resumed the same persistent thread, asked Codex to answer from what it had already read, and then verified every useful point against the source.

  1. Codex challenged the claims.It found that lease protection was process-local, history output was truncated, and shared TUI threads required a specific remote connection.
  2. Claude checked the code.It confirmed the valid findings and corrected the README, including sandbox, approval, testing, and token-budget details.
  3. The thread survived the interruption.The two review turns used about 330k tokens in total, but the second continued with the first turn’s context intact.
That is the point of Connect: another model can question assumptions the first model carried through its work.

Use it

Five commands.

/connect:ask <question>Ask Codex in a persistent thread.
/connect:threadsList recent Codex conversations.
/connect:resume <threadId> <question>Continue an earlier conversation.
/connect:configChoose the model, effort, and token ceilings.
/connect:doctorCheck the daemon and integration health.

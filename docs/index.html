02 / See it in action

Ask naturally.
Get a second mind.

Use a slash command, or simply tell Claude to ask Codex. Connect chooses the right amount of reasoning for the job.

YOU → CLAUDE

Ask Codex to review the payment callback diff for security issues.

Connect routes as code_review
CODEX

Two issues: the signature is compared after parsing attacker-controlled fields, and the idempotency key is written after fulfilment. Verify the raw body first, then claim the key atomically.

YOU → CLAUDE

Get a second opinion from Codex: should this cache live in-process or in Redis?

Connect routes as second_opinion
CODEX

Keep it in-process while one worker owns each key. Move to Redis only when cross-worker consistency becomes a real requirement; today it adds a network dependency without solving an observed problem.

YOU → CLAUDE

Have Codex stress-test the lease protocol for split-brain and clock skew.

Connect routes as deep_reasoning
CODEX

Wall-clock expiry alone cannot fence a paused writer. Add a monotonically increasing token to every lease and require it on writes; the storage layer must reject tokens older than the latest issued value.

YOU → CLAUDE

Ask Codex to implement the fix and update the focused test.

Connect routes as implement
CODEX

Updated the lease guard to reject stale fencing tokens and added a concurrent-writer regression test. The focused suite passes: 18 checks, 0 failures.

03 / Built-in judgment

Every question gets
the right-sized brain.

A one-line fact should not cost the same as a race-condition audit. Connect pins effort and a token ceiling on every turn.

06 / Questions

The practical details.

Does Connect send my code to another service?

Connect asks the local Codex app-server to run Codex against your working directory. The same OpenAI account and Codex setup you already use apply. Review and reasoning routes are read-only; only the explicit implementation route can edit workspace files.

Does it install npm packages?

No. The plugin and MCP server use Node.js built-ins only. You do need the standalone Codex installation because Connect talks to its shared local daemon.

Can I continue an earlier conversation?

Yes. Every answer includes a thread ID. Use /connect:resume <threadId> <question>, or list recent conversations with /connect:threads.

Can I choose the Codex model and reasoning level?

Yes. /connect:config opens an interactive picker for the model, effort, token ceilings, and what should happen to existing threads after a model change.

Why use two coding models?

They fail differently. An independent model can spot an assumption the first model carried through its entire answer. Connect makes that cross-check quick enough to use on the decisions that deserve it.
